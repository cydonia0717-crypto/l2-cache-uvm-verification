# Non-blocking L2 Cache UVM Verification

A portfolio-grade digital IC verification project using the open-source Vortex cache RTL as DUT and a newly built SystemVerilog/UVM testbench.

## DUT configuration

- 256 KiB, 4-way, 64-byte line
- 4 banks, 2 upstream request ports
- 64-bit word access
- 8-entry MSHR per bank
- write-back + write-allocate
- pseudo-LRU
- tagged memory refill interface with response reordering support

## Why this project

The project is designed around CPU/NPU/SoC memory-subsystem verification topics that are commonly difficult in real designs: MSHR pressure, concurrent misses, same-line dependencies, refill routing, dirty eviction, replacement and multi-layer backpressure.

## Quick start

```bash
./scripts/setup_vortex.sh
TEST=l2_smoke_test SEED=1 ./scripts/run_vcs.sh
python3 scripts/regression.py --seeds 5
```

Requirements: Linux, Synopsys VCS with UVM 1.2 support, Python 3, Git. Verdi can open the VCS debug database generated by `-debug_access+all -kdb`.

The setup script pins Vortex to commit `a4afb2351f4b4464a53779874616d95571c376d0` for reproducibility.

## Current milestone

The repository contains the DUT wrapper, two active core agents, reactive memory model with latency/backpressure/out-of-order response injection, transaction-level scoreboard, first functional coverage model, boundary SVA, six directed/stress tests and regression automation.

This archive has been statically checked for project structure and Python/shell syntax. It has **not** been executed under VCS in the ChatGPT runtime because VCS is not installed there. Run the smoke test in the target Linux EDA environment before treating the regression as validated.

See `docs/Verification_Plan.md` and `docs/Interview_Notes.md` before extending the project.

## Milestone 2: reproducible simulator bring-up

Two execution paths are now maintained:

- **VCS/Verdi**: primary interview/industry flow (`scripts/run_vcs.sh`).
- **Verilator v5.052 + Verilator-compatible UVM**: open-source CI/smoke flow (`scripts/bootstrap_oss.sh`, `scripts/run_verilator.sh`).

`SIM=auto ./scripts/run.sh` selects VCS when available and otherwise Verilator.

A GitHub Actions workflow is included at `.github/workflows/oss-smoke.yml`; once this project is pushed to a repository, it bootstraps the open-source toolchain and runs smoke, same-line merge, and MSHR-pressure tests automatically.
